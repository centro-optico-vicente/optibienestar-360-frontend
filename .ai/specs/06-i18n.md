# 06 — i18n (Internacionalización)

## Configuración

```typescript
// nuxt.config.ts
modules: ['@nuxtjs/i18n'],
i18n: {
  locales: [
    { code: 'es', name: 'Español', file: 'es.json' }
  ],
  defaultLocale: 'es',
  strategy: 'no_prefix',  // no agregar /es/ a URLs
  lazy: true,
  langDir: 'locales/',
}
```

## Reglas

- **Toda string visible al usuario debe estar en `es.json`** — no hardcodear en componentes
- **Nested keys por dominio** — facilita encontrar y mantener
- **NO incluir HTML en strings** — usar componentes para markup
- **Pluralización:** usar Vue I18n syntax `'{count} afiliado | {count} afiliados'`
- **Interpolación:** `'Hola, {name}'` + `t('greeting', { name: 'Juan' })`

## Formato de fechas / números

Usar `useFormatters` composable + i18n:

```typescript
// composables/useFormatters.ts
export const useFormatters = () => {
  const formatCurrency = (amount: number, currency = 'USD') =>
    new Intl.NumberFormat('es-VE', { style: 'currency', currency }).format(amount);

  const formatDate = (date: string | Date, format: 'short' | 'long' = 'short') => {
    const d = typeof date === 'string' ? new Date(date) : date;
    if (format === 'long') {
      return new Intl.DateTimeFormat('es-VE', { day: 'numeric', month: 'long', year: 'numeric' }).format(d);
    }
    return new Intl.DateTimeFormat('es-VE').format(d);
  };

  const formatRelative = (date: string | Date) => {
    // "hace 3 días", "en 2 semanas"
    const rtf = new Intl.RelativeTimeFormat('es-VE', { numeric: 'auto' });
    // ... lógica
  };

  return { formatCurrency, formatDate, formatRelative };
};
```

Uso:
```vue
<script setup>
const { formatCurrency, formatDate } = useFormatters();
</script>
<template>
  <td>{{ formatCurrency(payment.amount) }}</td>
  <td>{{ formatDate(membership.next_due_date, 'long') }}</td>
</template>
```

## Futuro: multi-idioma

Si en el futuro se agrega inglés u otro idioma:
1. Crear `locales/en.json` con mismas keys
2. Agregar locale al config Nuxt
3. Mostrar selector de idioma en header
4. Considerar `strategy: 'prefix_except_default'` (urls `/en/...`)

Por ahora, audiencia 100% hispanohablante.
